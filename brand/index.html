Hash Block brand

A page for a markdown file. Open one. Nothing is written back. The identity is two pieces the product already had: the # its welcome screen draws in IBM Plex Mono, and the H1 its page sets in Source Serif 4.

The mark

Plex Mono's # is open in the middle: its bars stop at each stroke and never cross the gap. The mark keeps Plex's slant, bar heights and arm length, and is set 1.4× heavier with a 1.75× wider gap, so that gap is still there at 16 px.

True pixels

16 is its own drawing, every edge on a whole pixel. From 24 up it is the master.

The rule

Source. Where you see syntax: the app icon, the favicon, the welcome screen. The # lives here.

Page. Where you read: titles, the README, a site. The name lives here.

They are one markdown line in two states, so they never share a line. Read aloud, # Hash Block is “hash Hash Block”; at a glance it is a hashtag; and the app's own page never shows it. Where both are needed, stack them.

Rules

  • The # and the name never share a line. Stack them where both are needed.
  • Below 24 px, use the 16 px drawing (mark-16.png, favicon.svg), never the master scaled down.
  • Never close the gap between the strokes, and never let a bar cross it: that is the generic #, and HASH's.
  • The mark is accent on paper or dark accent on ink. In one colour it is black or white, with the glyph a real hole.
  • The name is Source Serif 4 at 560, as the page's H1. Nothing is added to it.
