# Regenerating the Hash Block identity

Everything in this pack except the boards' round sheets, the text files and `index.html` is
generated by this folder. `verify.py` proves it.

Tested with Python 3.14 and Node 24.

```
npm ci
pip install -r requirements.txt
python build.py
node raster.js
python board.py
node raster.js board
```

The order matters. `board.py` places the files `build.py` writes, and `raster.js board`
rasterises the boards `board.py` writes.

| File | Does |
|---|---|
| `build.py` | The source of truth: parameters, palette, every SVG in `dist/svg/`, and the checks (no `<text>`, a `<title>` in each, contrast, the 16 px grid). |
| `geom.py` | The open hash. `PLEX` holds Plex Mono 500's `#`, measured. `open_hash()` is the master, and `open_hash_16()` is the 16 px drawing. |
| `glyphs.py` | Letters as outlines: HarfBuzz shaping on the instanced variable font, so the name is kerned the way the page kerns it. |
| `board.py` | The brand board and the in-context sheet, built by placing `dist/svg/` files. |
| `raster.js` | PNG, ICO, ICNS and the Tauri set, from `dist/svg/`. |
| `verify.py` | Regenerate, then compare every asset against the pack, byte for byte. |

To change the mark, change `MASTER` or `SIXTEEN` in `build.py` and rebuild. The palette is the
product's own; change it in the product first.
