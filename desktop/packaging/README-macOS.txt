Hash Block @VERSION@ for macOS

Hash Block opens a markdown file as a page, in a window of its own. It reads, and nothing in it can write, so your files are safe from it, and from me.

What is in here

- Hash Block.app: the app.
- README.txt: this. It would be a README.md, but you have not installed the thing that reads those yet.

Installing

1. Drag Hash Block.app into Applications.
2. Open it. The first time, macOS will not, since the app is not signed with an Apple Developer ID yet. In System Settings, Privacy & Security, choose Open Anyway.
3. Double-click a .md file. If another app opens it, choose Get Info on the file, set Open with to Hash Block, and choose Change All.

It needs macOS 11 or later on Apple silicon. There is no Intel build yet.

Uninstalling

Drag Hash Block.app from Applications to the Bin.
